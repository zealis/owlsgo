# owlsgo · 安装指南

面向「拿到代码后怎么把它跑起来」的**操作清单**。每一步末尾都有**验证方法**，
照着做不会出现「看起来装好了其实没装对」。

> 想先了解项目本身，看 [`../README.md`](../README.md)。
> 想写插件，看 [`插件开发规范.md`](./插件开发规范.md)。

---

## 0. 三种方式怎么选

| 场景 | 用哪种 | 耗时 |
| --- | --- | --- |
| Windows，装了 phpStudy / 宝塔 / 小皮 | **方式一：图形化面板** | ~3 分钟 |
| 只想先看看长什么样，不想配服务器 | **方式二：PHP 内置服务器** | ~1 分钟 |
| VPS / 云服务器（Linux） | **方式三：Nginx 或 Apache** | ~10 分钟 |

三种方式装完是**同一个站点**，后续可以随时换。

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| PHP | **8.1 及以上** |
| 必需扩展 | `pdo`、`mbstring`、`json` |
| 强烈建议扩展 | `fileinfo`（上传 MIME 检测）。**不装也能跑**，但附件类型判定会失准：图片（走 `getimagesize`）正常，`.txt`/`.md`/`.zip`/`.pdf` 这类会被误判成 `application/octet-stream` 而拒收。 |
| 数据库扩展 | `pdo_sqlite`（推荐，零配置）**或** `pdo_mysql` **或** `pdo_pgsql` |
| 数据库 | SQLite 3 / MySQL 8.0+ / PostgreSQL 13+ |
| 可选扩展 | `gd`（头像、验证码等图片处理）、`openssl`（生成密钥） |

**没有 URL 重写也能跑**：核心会自动降级成 `/index.php?r=/t/12` 形态，不用改代码。

先用一条命令确认 PHP 本身没问题：

```bash
php -v
php -m | grep -iE "pdo_sqlite|pdo_mysql|mbstring|fileinfo|gd"
```

## 2. 方式一：phpStudy Pro / 小皮面板（Windows 图形化）

### 2.1 选 PHP 版本并开扩展

1. 启动面板 →「软件管理 → PHP」，选一个 **≥ 8.1** 的版本（如 `php8.2.9nts`）。
2. 「设置 → 扩展」，勾选：

   | 扩展 | 用途 |
   | --- | --- |
   | `pdo_sqlite` | 默认数据库，零配置 |
   | `mbstring`、`json` | 必需 |
   | `fileinfo` | 强烈建议：不装的话 `.txt`/`.zip`/`.pdf` 等非图片附件会被误判成 `application/octet-stream` 而拒收 |
   | `gd` | 图片处理（建议开） |

3. **验证**：面板「设置 → 环境」能看到 `php.exe` 路径，在 CMD 里执行它 `-m`，
   输出里应能看到上表中的扩展名。

> **phpStudy 的经典坑：GD 扩展名写错。**
> 它的 `php.ini` 里 GD 那行常写成 `extension=gd2`，而自带的 DLL 实际叫 `php_gd.dll`。
> 名字对不上 → PHP 启动告警，且 GD **不会加载**（头像/验证码功能会莫名失败）。
> 把该行改成 `extension=php_gd.dll` 即可，改前建议先备份 `php.ini`。

### 2.2 新建网站

「网站 → 创建网站」，按下表填写：

| 项目 | 填写内容 |
| --- | --- |
| 域名 | 例如 `owlsgo.test`（勾选「同步 hosts」，省得手动改 hosts 文件） |
| 根目录 | `<项目路径>\forum\public` ← **必须指向 `public/`** |
| PHP 版本 | 2.1 选定的版本 |

> **最容易错的一步：根目录填成 `forum/`。**
> 填错的后果不是打不开，而是**页面 URL 全都多出一段 `/public/`**（走了降级方案）。
> 如果确实只能指向 `forum/`，仓库里附带的 `forum/.htaccess` 会自动处理，
> 再在 `config/app.php` 里设 `'base_path' => ''` 就能去掉那段前缀。

> **强烈建议：根目录直接指向你的代码目录，不要复制到 `WWW/`。**
> 很多人习惯把项目拷进 `WWW/forum` 再去建站，结果**同一个项目存在两份拷贝**：
> 改了源目录、站点却没变，然后开始怀疑人生。
> 直接把根目录填成 `<你的代码目录>\forum\public`（例如
> `D:\Project files\owlsgo\forum\public`）即可 —— 只有一份代码，改完刷新就生效。
>
> 如果已经复制了一份到 `WWW/`，改完源目录后可以用 robocopy 同步
> （**必须排除 `storage/`**，否则会把站点数据库覆盖掉）：
>
> ```bat
> robocopy "D:\Project files\owlsgo\forum" "D:\Program Files (x86)\phpstudy_pro\WWW\forum" /E /XD storage
> ```
>
> 或者更省事：删掉 `WWW\forum`，按上面的建议把根目录改指到代码目录。

### 2.3 让伪静态生效

**Apache 用户**：打开「网站 → 管理 → 修改 → 配置文件」，确认 `<Directory>` 段内是：

```apache
<Directory "D:/www/owlsgo/forum/public">
    AllowOverride All      # 关键！默认可能是 None
    Require all granted
</Directory>
```

保存后**重启 Apache**。

> `AllowOverride` 不是 `All` 时，`.htaccess` 会被完全忽略 →
> 首页能打开，但**点任何链接都 404**。

**Nginx 用户（小皮面板默认就是 Nginx）**：**必须配伪静态**，否则首页能开、
但 `/install`、`/login`、`/t/12` 全部 404（详见 2.5）。

面板里做：**「网站 → 管理 → 伪静态」**，粘贴下面这一行后保存（保存会自动重载 Nginx）：

```nginx
try_files $uri $uri/ /index.php?$query_string;
```

不想用面板，就把规则抄进站点自己的 `vhosts/*.conf`：

```nginx
root /path/to/owlsgo/forum/public;
index index.php;

location / {
    try_files $uri $uri/ /index.php?$query_string;   # 关键行，不能少
}

location ~ \.php$ {
    include fastcgi_params;
    fastcgi_pass 127.0.0.1:9000;                      # 按面板显示的 PHP-FPM 地址调整
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
}
```

> **`try_files` 是唯一不能少的一行。** 少了它，`/` 因为 `index index.php` 还能打开，
> 但其他地址会因为「文件不存在」被 Nginx 直接拒掉 —— 请求**根本进不了 PHP**。
> 末尾的 `$query_string` 也别丢，否则分页与搜索参数会被吞掉。

> ⚠️ 面板「伪静态」框里**只能填 `location` 级指令**。完整 `location { ... }` 块写进去会让
> Nginx 启动失败 —— 因为该文件是被 `include` 在 `location /` **内部**的，不允许嵌套。

### 2.4 顺便确认监听端口

phpStudy 给 `localhost` 建的默认站点可能**只监听 443**。这时 `http://localhost/` 打不开，
请用 `https://localhost/`（自签证书点「继续访问」），或在「网站 → 管理 → 修改」里加一个 `80` 端口。

### 2.5 打开就是 404？先判断是哪一层出的问题

这一步能省掉大量瞎试。看 404 页面的**长相**：

| 你看到的 | 谁返回的 | 说明 |
| --- | --- | --- |
| 英文 **404 Not Found**（小皮/nginx 自带错误页） | Nginx | 请求**没进 PHP**。查：站点根目录是否指向 `public/`；`nginx.htaccess` 是否为空；面板「伪静态」是否配了 `try_files`。 |
| 中文 **404 页面不存在**（论坛自己的蓝白页面） | 本程序 | 请求**已进 PHP**，只是路由没匹配。伪静态是好的，检查 URL 或该内容是否已删。 |
| 中文 **403 没有权限** | 本程序 | 伪静态正常，是权限判定拦下的（例如「站务公告」版块不允许发帖）。 |

命令行判定更干脆：

```bash
curl -sk -o /dev/null -w "%{http_code}\n" https://localhost/install
# 200 = 正常；404 = 卡在 Nginx 层
```

**「首页能开、其他地址 404」这个组合，几乎一定是缺 `try_files`。**

### 2.6 装

浏览器打开站点 → 自动跳到 `/install` → 按向导走完。

## 3. 方式二：PHP 内置服务器（最快，不需要 Web 服务器）

适合「我就想先跑起来看看」。仓库附了 `forum/router.php`，因为内置服务器**没有 URL 重写**，
不加路由脚本的话伪静态地址（`/t/12`）会 404。

```bat
cd /d "D:\Project files\owlsgo\forum"
"D:\Program Files (x86)\phpstudy_pro\Extensions\php\php8.2.9nts\php.exe" -S 127.0.0.1:8080 -t public router.php
```

（`php.exe` 换成你自己的路径即可，Linux/macOS 就写 `php`。）

然后打开 `http://127.0.0.1:8080/`。

**两个必须注意的点**：

- `-t public` **不能省**。少了它，框架探测出站点的「基础路径」会是错的，
  全站链接会变成 `\/install` 这种畸形 URL。
- 这个方式**不需要** Apache/Nginx，也**不依赖** `.htaccess`。

只想全站用兼容形态（`/index.php?r=/t/12`）、连 `router.php` 都不想要的话，
在 `config/app.php` 里设 `'pretty_url' => false` 即可。

## 4. 方式三：Nginx / Apache（Linux 服务器常规部署）

1. **上传代码**：只需 `forum/` 目录（`storage/` 下的运行时内容不必上传）。

2. **站点根目录指向 `forum/public/`**（**不是** `forum/`）。

3. **配伪静态**：

   - **Apache**：仓库已附带两份可直接用的 `.htaccess`，开启 `mod_rewrite` 与
     `AllowOverride` 即自动生效。

     | 场景 | 站点根目录 | 生效文件 |
     | --- | --- | --- |
     | 推荐 | `forum/public/` | `public/.htaccess` |
     | 降级（主机商不让改根目录） | `forum/` | `forum/.htaccess` |

   - **Nginx**：粘贴 [README 的 Nginx 配置](../README.md#nginx)。

4. **给写权限**：`storage/` 需要 Web 进程可写（子目录会自动创建）。

   ```bash
   chmod -R 755 storage
   chown -R www-data:www-data storage   # 按实际 Web 用户调整
   ```

5. 访问域名 → 自动跳 `/install`。

## 5. 安装向导会做什么

1. **环境自检** —— 检查 PHP 版本、扩展、目录写权限。
2. **填写数据库** —— 选 SQLite 就什么都不用填；选 MySQL/PostgreSQL 则填连接信息。
3. **创建管理员账号** —— 这个账号就是后台超管，密码请自己记好。
4. **建表 + 写入初始数据**。

装完会生成两个文件：

| 文件 | 说明 |
| --- | --- |
| `storage/config/database.php` | 含真实凭据的数据库配置（**已在 `.gitignore` 中，不会入库**） |
| `storage/install.lock` | 安装锁。存在它之后，`/install` 会自动跳回首页 |

## 6. 装完之后

- **进后台**：`/admin`（用向导里创建的管理员账号登录）。
- **建版块**：「后台 → 版块管理」。
- **改站点信息**：「后台 → 站点设置」—— 侧栏里这一项是个可展开的分组，
  下面每个条目都是独立页面：基本信息 / 注册与登录 / 帖子 / 附件 / 系统与维护
  （站名描述、注册与验证码开关、审核与发帖间隔、长内容折叠、附件上限、维护模式等都在对应页面里，
  页面改完发现前台没变化时，去「系统与维护」清一次 OPcache）。
- **配计划任务**（可选，用于清理过期会话/日志）：见 [README「计划任务配置」](../README.md#计划任务配置)。
- **试插件**：启用内置示例插件 `owlsgo-demo`（「后台 → 插件管理」），
  它会演示正文装饰、活动记录、前台路由、后台页面、导航菜单、用户中心标签页等能力。
  写自己的插件看 [`插件开发规范.md`](./插件开发规范.md)。

## 7. 排查速查表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 首页跳到了 `/install` | 没装过（无 `install.lock`） | 完成安装向导；迁移站点则确认 `storage/` 已拷贝且有写权限 |
| 想重装 / 重置 | — | 删 `storage/install.lock`（换库再删 `storage/config/database.php`）后重新访问 `/install` |
| 首页正常，点链接全 404 | URL 重写没生效 | Apache 查 `mod_rewrite` + `AllowOverride All`；Nginx 查 `try_files`（面板「伪静态」）；或临时设 `'pretty_url' => false` |
| 打开就 **404 Not Found**（英文、面板样式） | 请求没进 PHP | 见 2.5：根目录是否指向 `public/`；`nginx.htaccess` 是否为空；伪静态是否配了 `try_files` |
| 打开是 **404 页面不存在**（中文、论坛样式） | 已进 PHP，路由没匹配 | 伪静态正常，检查 URL 拼写或内容是否已删除 |
| 打开是 **403 没有权限** | 已进 PHP，被权限拦下 | 例如「站务公告」版块不允许发帖，换版块试 |
| 点「开始安装」弹出「服务器返回了无法解析的内容」；控制台 POST 403，URL 是 `[object HTMLButtonElement]` | JS 把按钮对象当 URL 了 | 已修复：更新 `public/assets/js/app.js`；刷新页面让浏览器加载 `app.js?v=...` 新版 |
| 改了代码，站点却没变化 | 有两份拷贝（源目录 + `WWW/` 各一份） | 见 2.2 的建议：把根目录直接指向代码目录，或用 robocopy 同步（排除 `storage/`） |
| `http://localhost/` 打不开但 `https://` 可以 | 默认站点只监听了 443 | 改用 `https://`，或在面板给站点加 `80` 端口 |
| URL 里多出 `/public/` | 根目录指向了 `forum/` | 改指向 `forum/public/`，或设 `'base_path' => ''` |
| 子目录部署，样式和链接错位 | 基础路径没配对 | 设 `'base_path' => '/forum'`，并解开 `public/.htaccess` 的 `RewriteBase` |
| 样式 / 图标丢失 | 根目录不对或资源没传全 | 确认根目录是 `public/`，且 `public/assets/` 完整 |
| 表单提交报 **419** | 缺 CSRF 字段 | 确认表单里有 `<?= csrf_field() ?>` |
| 表单提交报 **429** | 触发限流 | 等窗口期结束；阈值在 `config/app.php` 的 `rate_limit` |
| 上传失败 | 三处大小限制 | `upload_max_filesize`、`post_max_size`、Nginx `client_max_body_size` 都要 ≥ 后台上限 |
| 头像 / 验证码图裂 | GD 没加载 | 见 2.1 的 GD 扩展名坑 |
| 插件合并资源没更新 | 缓存签名未变 | 删 `storage/cache/plugins.css`、`plugins.js`、`.signature` 强制重建 |
